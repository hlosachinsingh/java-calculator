# Java Calculator 

A simple, menu-driven calculator built using Java. This project was created to practice Java fundamentals, methods, user input, conditional logic, and loops.

## Features

- Addition of two numbers
- Subtraction of two numbers
- Multiplication of two numbers
- Division with division-by-zero checking
- Power calculation using `Math.pow()`
- Interactive menu using a `switch` statement
- Repeated calculations using a `do-while` loop
- Invalid menu choice handling
- Decimal number support

## Technologies Used

- **Language:** Java
- **Input:** `Scanner`
- **Concepts:** Methods, variables, `switch` statements, conditional statements, and loops
- **IDE:** IntelliJ IDEA

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed
- IntelliJ IDEA or another Java-compatible IDE

### How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open the `Calculator.java` file inside the `src` folder.
4. Run the `Calculator` class.
5. Follow the instructions displayed in the console.

## Usage

1. Run the program.
2. Choose an operation from the menu.
3. Enter the required numbers.
4. View the result in the console.
5. Continue calculating or select the exit option to quit.
